# 小圈伪装开关对照测试

v2.2.0 采用默认关闭配置。下文的关闭组对应发布默认值，开启组对应显式设置 `letterMimicProbability: 1`。

在同样的 256 道六位大写字母验证码上，用 `createStrong({charPreset: 'ABCDEFGHIJKLMNOPQRSTUVWXYZ', letterMimicProbability: 0})` 生成关闭组，将概率改为 `1` 生成开启组。开启后，Luna、Terra、Sol 分别少通过 13、6、9 道。对 Luna 影响最大的是 C → G，P → R 在三个模型上都很少诱发预期误读。

## 整题识别结果

六个字母全部正确才算通过。百分点差值按未舍入的原始计数计算。最后两列记录同一题在两次读图中只在哪一侧答对。

| 模型 | 关闭小圈 | 开启小圈 | 开启减关闭 | 仅关闭时答对 | 仅开启时答对 |
| --- | ---: | ---: | ---: | ---: | ---: |
| GPT-6 Luna | 89/256（34.8%） | 76/256（29.7%） | −5.1 个百分点 | 21 | 8 |
| GPT-6.1 Terra | 204/256（79.7%） | 198/256（77.3%） | −2.3 个百分点 | 9 | 3 |
| GPT-6.2 Sol | 207/256（80.9%） | 198/256（77.3%） | −3.5 个百分点 | 17 | 8 |

按上述配对计数计算，双侧精确 McNemar 检验的原始 p 值分别为 0.024、0.146、0.108。将三个模型一起作 Holm 多重比较校正后，均未达到 0.05。三个点估计都向下，这批样本仍不足以确认三类模型均有稳定收益。

## 小圈实际出现时

256 道随机题中，137 道含有 P、F 或 C。开启时其中 84 道通过布局检查并实际加圈，占全部题的 32.8%。其余 172 对图片逐字节相同。这 172 道保留在总通过率的分母中。

| 模型 | 84 道同底图，关闭时通过 | 84 道同底图，开启时通过 | 差值 |
| --- | ---: | ---: | ---: |
| GPT-6 Luna | 31/84（36.9%） | 18/84（21.4%） | −15.5 个百分点 |
| GPT-6.1 Terra | 73/84（86.9%） | 67/84（79.8%） | −7.1 个百分点 |
| GPT-6.2 Sol | 70/84（83.3%） | 61/84（72.6%） | −10.7 个百分点 |

下表只看小圈所在的字符位置。箭头两边分别为关闭、开启时将原字母读成指定目标字母的次数。

| 映射 | 实际加圈题数 | Luna | Terra | Sol |
| --- | ---: | ---: | ---: | ---: |
| P → R | 20 | 0 → 0 | 0 → 1 | 0 → 0 |
| F → E | 36 | 0 → 3 | 0 → 2 | 0 → 3 |
| C → G | 28 | 2 → 22 | 0 → 2 | 0 → 5 |

## 测试与复核

- 测试代码版本为 `090d6a9`。连续抽取 256 道新题，内置字体、六位 A–Z、210 × 68 像素、三条噪线。每对按同一随机输入生成，答案、字形、颜色、布局、噪线均配对。关闭组的 256 张 PNG 还逐字节对上了加入小圈前的版本 `9d2e7d1`。两个开关位置的全部 512 个输出都经过独立重放和 SHA-256 核对。
- 对 84 对不同的图，每个模型在两个独立上下文中各读一张，开启图与关闭图按 42∶42 均衡分配，再打乱顺序。其余 172 对的输入完全相同，每个模型每图只读一次，两组沿用同一次作答。这样相同像素上的重复作答波动不会计入开关差值。
- 每个模型读 340 张不同的 PNG，三个模型合计 1,020 份原始作答。只展示编号和统一放大两倍的题图，提示按连续实线读出六个大写字母。按指令隔离材料，不提供答案、开关状态或正确性反馈。读图代理未显式指定推理档位。
- 逐题记录给出答案、两组图片编号与哈希、发生像素变化的位置及三种模型的读数。对压缩包内的原图另行解码，复核了每一对的差异位置，并由原始作答重算通过数。[逐题结果](results.json) · [340 张盲测原图](images.zip)

建议把当前默认尝试概率从 `0.5` 改为 `0`，再作为显式开启的实验选项合入。两个较强模型在完全开启后仍各通过 198/256 道，尚未测量真人首次通过率和作答耗时。
